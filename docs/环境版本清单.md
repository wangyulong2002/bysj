## 关键配置

### WSL 网络与路径
- 项目应放在 WSL 文件系统内（如 `~/bysj`），**不使用 `/mnt/d`、`/mnt/c` 等 Windows 挂载点**（跨文件系统 IO 慢、权限异常）。Maven 3.9.9 位于 WSL 内 `/home/heart/tools/apache-maven-3.9.9`（`/mnt/d/Maven/` 有旧副本，勿再使用）。
- **端口约定**：WSL 内访问 `127.0.0.1:3306` 可能命中 Windows 宿主侧的 MySQL 8.0.40（WSL2 localhost 转发），与 Docker MySQL 混淆。因此本项目 MySQL 统一使用 **端口 3307**。
- WSL 服务监听：后端服务（FastAPI 8080、RuoYi 8081 等）默认绑定 `0.0.0.0`，WSL 内及局域网内可经 `localhost` 或 `wsl hostname -I` 访问。

### MySQL（Docker 容器 `campus-mysql`）
- 容器：`campus-mysql`（镜像 `mysql:8`，`--restart always`，数据卷 `campus-mysql-data`）
- 连接：**`127.0.0.1:3307`**，用户 `root`，密码 `123456`
- 已建数据库：`campus`（业务库，utf8mb4 / utf8mb4_unicode_ci）、`ry`（若依库，2026-07-15 导入）
- 字符集参数：`--character-set-server=utf8mb4 --collation-server=utf8mb4_unicode_ci`
- 时区：`TZ=Asia/Shanghai`
- 常用命令：
  - `docker exec -it campus-mysql mysql -uroot -p123456`
  - `docker logs campus-mysql`
  - `docker start/stop campus-mysql`

### Redis（Docker 容器 `redis-stack`）
