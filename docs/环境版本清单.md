- 连接：`127.0.0.1:3306`，用户 `root`，密码 `123456`

### Redis（Redis Stack）
- 连接：`redis://127.0.0.1:6379/0`（Docker 容器 redis-stack，宿主机映射 6379）
- RediSearch：已验证模块加载，可执行 `FT.CREATE`
- 已有索引 `pdd_cs_faq`（拼多多客服项目，与本项目无关）

### Maven 修复记录
- 问题：`mvn -version` 报「找不到或无法加载主类 org.codehaus.plexus.classworlds.launcher.Launcher」
- 根因：`JAVA_HOME` 环境变量未设置，且 Git Bash 下 MSYS 路径（`/d/...`）不被 Windows 原生 java 识别
- 修复：`setx JAVA_HOME "C:\Program Files\Java\jdk1.8.0_261"`、`setx MAVEN_HOME "D:\Maven\apache-maven-3.9.9"`
