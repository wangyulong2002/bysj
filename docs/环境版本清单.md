## 关键配置

### WSL 网络与路径
- 项目应放在 WSL 文件系统内（如 `~/bysj`），**不使用 `/mnt/d`、`/mnt/c` 等 Windows 挂载点**（跨文件系统 IO 慢、权限异常）。
- **端口约定**：WSL 内访问 `127.0.0.1:3306` 可能命中 Windows 宿主侧的 MySQL 8.0.40（WSL2 localhost 转发），与 Docker MySQL 混淆。因此本项目 MySQL 统一使用 **端口 3307**。
- WSL 服务监听：后端服务（FastAPI 8000、Django 8001 等）默认绑定 `0.0.0.0`，WSL 内及局域网内可经 `localhost` 或 `wsl hostname -I` 访问。

### MySQL（Docker 容器 `campus-mysql`）
- 容器：`campus-mysql`（镜像 `mysql:8`，`--restart always`，数据卷 `campus-mysql-data`）
- 连接：**`127.0.0.1:3307`**，用户 `root`，密码 `123456`
- 已建数据库：`campus`（业务库，utf8mb4 / utf8mb4_unicode_ci）；`ry`（若依库，v2.0 起不再依赖，可保留历史数据）
- 字符集参数：`--character-set-server=utf8mb4 --collation-server=utf8mb4_unicode_ci`
- 时区：`TZ=Asia/Shanghai`
- 常用命令：
  - `docker exec -it campus-mysql mysql -uroot -p123456`
  - `docker logs campus-mysql`
  - `docker start/stop campus-mysql`

### Redis（Docker 容器 `redis-stack`）
- 连接：`127.0.0.1:6379`，密码 `123456`
- RediSearch：已验证模块加载，可执行 `FT.CREATE`
- 已有索引 `pdd_cs_faq`（拼多多客服项目，与本项目无关）
- 版本：Redis 7.4.7

### Django 管理端部署说明（T0-2，v2.1）
- 工程：`bysj/manage/`（Django 项目 `config/` + 业务 Apps），端口 **8001**（开发 `runserver`，生产 gunicorn）
- 依赖：**Django 5.2 LTS** + Django REST Framework + mysqlclient/PyMySQL，安装于 `server/venv_wsl/`（A-01：Python 3.14 需 Django 5.2+）
- 数据库：共享 `campus` 库（连接配置由 `bysj/.env` 提供，`127.0.0.1:3307`）；`sys_user` 精简自建，不再依赖 `ry` 库
- 验证：管理员登录 Django Admin、DRF `/admin/api/**` 接口鉴权（对应验收标准 7）


### 构建环境注意事项（WSL）
- npm 依赖安装在 WSL 内；若 npm 缓存异常：`npm cache clean --force` 后重试。
- sudo 需交互密码；如需自动化系统级操作可临时配置 NOPASSWD（注意安全）。
